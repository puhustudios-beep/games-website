# games.puhustudios.com

Puhu Studios games website. Static single-page site (HTML/CSS/JS, no build step).

## Structure

- `index.html` — the whole site
- `screen-*.webp` — game screenshots
- `CNAME` — custom domain for GitHub Pages

## Deploy (GitHub Pages)

1. Settings → Pages → Deploy from branch → `main` / root
2. DNS: add a CNAME record `games` → `<username>.github.io`
